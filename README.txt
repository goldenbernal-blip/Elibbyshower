ELIAN VERCEL SITE

This folder is a complete static website. Keep index.html and the assets folder together.

To deploy on Vercel:
1. Upload this folder to a GitHub repository, or use the Vercel CLI from this folder.
2. In Vercel, import the repository as a new project.
3. Select "Other" as the framework preset if Vercel asks.
4. Leave the build command empty and set the output directory to ".".
5. Deploy.

No package installation, environment variables, or build step is required.
